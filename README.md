## Selected work

**Sigap Assistant** · 2026 · take-home test for Brand N Purpose · [code](https://github.com/Marpfirst/sigap-assistant) · [live demo](https://rag-chatbot-marp.vercel.app)<br>
Two-agent helpdesk assistant where every token is measured and shown.<br>
`Next.js 14` `TypeScript` `Supabase pgvector`

**BAAK Academic Chatbot** · 2025 · undergraduate thesis · [code](https://github.com/Marpfirst/Chatbot-baak)<br>
Hybrid chatbot for a university academic office. Rules answer schedule, exam and calendar questions straight from the database; everything else goes through RAG over the office's guides. Scored 86.93% satisfaction in user acceptance testing with 28 students.<br>
`Python` `FastAPI` `Supabase` `Pinecone` `OpenAI API` `Docker` `Google Cloud Run`

**CV Ranker & Summarizer** · 2024 · [code](https://github.com/Capstone-Dicoding-C241-DJ02/Summarize-with-vertex-ai)<br>
Bangkit capstone for Dicoding Jobs, built by a team of six that I led. A T5 model summarizes each CV and a Doc2Vec model scores it against the job description. My part was the summarizer and a parser that extracts structured fields with Vertex AI, with an OCR fallback for scanned PDFs. Best Presenter, Bangkit Academy 2024.<br>
`Python` `Hugging Face T5` `PyTorch` `Vertex AI` `Gensim Doc2Vec` `Google Cloud Functions`

**MBG Management System** · 2026 · client work, in production<br>
Finance and operations dashboard for billing, payments, payroll and contracts. 13 modules with role-based access; invoices are generated weekly by a database job, rendered to PDF by a Python service and sent out through a WhatsApp gateway.<br>
`Next.js 14` `TypeScript` `Supabase` `PostgreSQL` `Python` · private repo, walkthrough on request

**Deception: Murder in Hong Kong** · 2025 · [play it live](https://www.deception.my.id/)<br>
Web version of the social deduction board game for 4–14 players, played from a private room link. The server owns every game state, and the game rules live in a separate, tested package.<br>
`Vue 3` `TypeScript` `Fastify` `Socket.IO` `Vitest`
